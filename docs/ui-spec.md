# 日志管理列表页 — 开发规格说明书

## 1. 页面概述

| 项目 | 说明 |
|---|---|
| 页面名称 | 日志管理（更新日志/通知管理） |
| 页面类型 | 后台管理列表页 |
| 核心功能 | 新增、编辑、删除、发布/下架、搜索、分页浏览 |
| 数据类型 | 当前仅一种类型：`AI学习室通知`（需确认是否预留扩展） |

## 3. 模块详细规格

### 3.1 新增日志按钮

| 属性 | 规格 |
|---|---|
| 文案 | `+新增日志` |
| 样式 | 主色调实心按钮（蓝 #409EFF 或项目主色），白字，圆角 |
| 位置 | 工具栏左侧 |
| 交互 | 点击 → 跳转新增页 或 弹出编辑弹窗（需确认交互形式） |
| 权限 | 需确认是否受角色权限控制 |

### 3.2 搜索模块

| 属性 | 规格 |
|---|---|
| 输入框 placeholder | `输入标题关键字搜索` |
| 搜索按钮 | 主色实心按钮，文案`搜索` |
| 触发方式 | ① 点击搜索按钮 ② 输入框内回车 |
| 匹配规则 | 按**标题字段模糊匹配**（LIKE %keyword%） |
| 搜索行为 | 触发后重置页码至第 1 页，保留搜索词在输入框中 |
| 清空行为 | 清空输入框后回车/点击搜索 → 恢复全量列表（需确认是否有 clear 事件即时触发） |

### 3.3 数据表格

#### 列定义

| 列名 | 字段（建议） | 类型 | 宽度建议 | 对齐 | 说明 |
|---|---|---|---|---|---|
| 序号 | — | 计算值 | 60px | 左 | 当前页内递增，翻页需确认：连续编号 or 每页重置（通常 `(page-1)*size + index + 1`） |
| 标题 | title | 文本 | 自适应 | 左 | 超长省略（ellipsis + tooltip 悬浮显示全文） |
| 类型 | type | 枚举 | 140px | 左 | 当前值固定为「AI学习室通知」 |
| 时间 | publishTime/createTime | datetime | 170px | 左 | 格式 `YYYY-MM-DD HH:mm`（注意：无秒） |
| 发布状态 | status | 布尔 | 100px | 左 | Switch 开关组件 |
| 点击量 | viewCount | int | 80px | 左 | 只读展示 |
| 操作 | — | — | 140px | 左 | 固定两个按钮：编辑、删除 |

#### 发布状态 Switch 规格

| 状态 | 视觉 | 含义 |
|---|---|---|
| 开（ON） | 主色填充 | 已发布，前端可见 |
| 关（OFF） | 灰色（当前截图全部为关闭态） | 未发布/已下架 |

**交互逻辑：**
- 点击即切换并调用更新接口，无需二次确认（需确认）
- 切换失败时回滚开关状态并 toast 报错
- ⚠️ 需确认：下架已发布日志是否影响已产生的点击量数据

#### 操作按钮

| 按钮 | 样式 | 行为 |
|---|---|---|
| 编辑 | 蓝色实心小按钮 | 跳转/弹窗进入编辑态，携带该行完整数据 |
| 删除 | 红色实心小按钮 | 点击 → **二次确认弹窗**（“确定删除该日志吗？”）→ 确认后调用删除接口 → 刷新列表 |

**删除补充规则：**
- 删除当前页最后一条数据后，应自动请求前一页
- 删除失败 toast 提示，列表不刷新

#### 空状态
- 搜索无结果 / 无数据时：显示空状态占位图 + 文案「暂无数据」

## 4. 分页规格

| 属性 | 规格 |
|---|---|
| 分页组件 | 页码按钮 + 上/下箭头 + 跳转输入框 + 总数文本 |
| 每页条数 | **10 条**（截图中第 1 页 10 条，共 15 条共 2 页） |
| 总数文案 | `共 {total} 条记录` |
| 跳转文案 | `前往 [input] 页`，输入超范围值需 clamp 到有效范围 |
| 默认状态 | 首页时「上一页」箭头置灰禁用；末页时「下一页」禁用 |
| 当前页高亮 | 主色填充 |
| 翻页行为 | 保留当前搜索条件；滚动位置回到列表顶部（需确认） |

## 5. 接口定义（建议）

### 5.1 分页查询

```
GET /api/logs?page={page}&pageSize=10&keyword={keyword}

Response:
{
  "code": 0,
  "data": {
    "total": 15,
    "list": [
      {
        "id": 1,
        "title": "冒烟测试",
        "type": "AI学习室通知",
        "time": "2025-08-27 22:53",
        "status": 0,          // 0=未发布 1=已发布
        "viewCount": 0
      }
    ]
  }
}
```

### 5.2 其他接口

| 接口 | 方法 | 路径 | 参数 |
|---|---|---|---|
| 新增 | POST | `/api/logs` | title、type、content、status |
| 编辑 | PUT | `/api/logs/{id}` | 同上 |
| 删除 | DELETE | `/api/logs/{id}` | — |
| 修改发布状态 | PUT | `/api/logs/{id}/status` | status |
| 详情 | GET | `/api/logs/{id}` | — |

## 6. 异常与边界处理

| 场景 | 处理方式 |
|---|---|
| 接口报错 | 全局 toast 错误信息，列表保持原状 |
| 加载中 | 表格显示 loading 遮罩，防重复提交（按钮防抖） |
| 删除进行中 | 确认弹窗确认按钮 loading，禁止重复点击 |
| 快速切换开关 | 请求未返回前禁用该开关或节流 |
| keyword 含 XSS 字符 | 前端转义展示，后端参数过滤 |
| 跳页输入非数字 | 过滤或提示，不可发起请求 |

## 7. 待确认问题清单 ⚠️

1. **新增/编辑的交互形式**：独立页面 or 弹窗？（影响路由设计）
2. **发布状态切换**是否需要二次确认？下架对用户端的影响？
3. **时间字段**是发布时间还是创建时间？切换发布状态时是否更新时间？
4. **类型字段**是否会有新增枚举（如「产品更新」「公告」），需确认是否做下拉筛选？
5. **删除**是物理删除还是逻辑删除？
6. **点击量**统计口径：用户端打开详情 +1？是否去重？
7. 序号翻页后是**连续编号**还是每页从 1 开始？
8. 是否需要**批量操作**（批量删除/批量发布）的预留？
9. 页面权限与操作权限（哪些角色可新增/删除）？
