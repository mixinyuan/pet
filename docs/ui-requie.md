# 日志管理页面 - 开发规格说明书

## 1. 页面概述

| 项目 | 说明 |
|------|------|
| 页面名称 | 日志管理（更新日志/通知管理） |
| 页面类型 | 后台管理列表页 |
| 核心功能 | 日志的增、删、改、查、发布状态切换、分页展示 |
| 数据来源 | 服务端接口（列表为分页数据，本例共 15 条记录） |

---

## 2. 页面布局结构

```
┌─────────────────────────────────────────────────┐
│ [+新增日志]                    [搜索输入框] [搜索] │  ← 工具栏区
├─────────────────────────────────────────────────┤
│ 序号│标题│类型│时间│发布状态│点击量│操作           │  ← 数据表格
│ ...                                             │
├─────────────────────────────────────────────────┤
│        [<] [1] [2] [>]  前往 [1] 页  共15条记录   │  ← 分页区
└─────────────────────────────────────────────────┘
```

整体为**卡片式容器**（白色背景、圆角、浅灰投影），页面背景为浅灰色。

---

## 3. 组件规格

### 3.1 新增按钮

| 属性 | 规格 |
|------|------|
| 文案 | `+ 新增日志` |
| 样式 | 蓝色背景（主色 `#1890FF` 或品牌蓝）、白字、圆角 4px |
| 右上角 | 附加蓝色标签角标（如图中的小标记，可标注快捷入口/必读提示） |
| 交互 | 点击 → 打开新增弹窗（或跳转新增页） |

**新增弹窗字段建议：**
- 标题（必填，输入框）
- 类型（必填，下拉选择，默认“AI自习室通知”）
- 内容（必填，富文本编辑器）
- 时间（默认当前时间，可编辑）

### 3.2 搜索区域

| 属性 | 规格 |
|------|------|
| 输入框 | placeholder：`输入标题关键字搜索`，宽度约 160px，右侧清空按钮（×） |
| 搜索按钮 | 蓝色底、白字，文案 `搜索`，与输入框间距 8~12px |
| 触发方式 | 点击按钮触发；**回车键同样触发**；清空输入框时恢复全量列表 |

**搜索逻辑：**
- 按标题做**模糊匹配**（`LIKE %keyword%`）
- 搜索后**重置页码为 1**
- 搜索结果需保留当前筛选条件下的分页

### 3.3 数据表格

#### 列定义

| 列名 | 字段 | 宽度建议 | 对齐 | 说明 |
|------|------|---------|------|------|
| 序号 | `index` | 60px | 左 | 跨页连续编号：(page-1)×pageSize + rowIndex + 1 |
| 标题 | `title` | 自适应 | 左 | 文字溢出省略（`text-overflow: ellipsis`），hover 显示 title 提示 |
| 类型 | `type` | 140px | 左 | 枚举值，当前数据均为「AI自习室通知」 |
| 时间 | `createTime` | 160px | 左 | 格式 `YYYY-MM-DD HH:mm` |
| 发布状态 | `publishStatus` | 100px | 居中 | Switch 开关组件 |
| 点击量 | `viewCount` | 80px | 左 | 数字，初始默认 0 |
| 操作 | — | 120px | 左 | 「编辑」+「删除」两个按钮，间距 8px |

#### 发布状态开关（Switch）

| 状态 | 样式 |
|------|------|
| 未发布（off） | 灰色，如图所示 |
| 已发布（on） | 蓝色/绿色（按设计规范确认，通常为主题蓝） |

**交互逻辑：**
- 点击切换 → 调用状态更新接口
- 请求期间开关置为 **loading/disabled**，防止重复点击
- 成功：更新本地状态 + 轻提示「发布成功 / 已下线」
- 失败：**回滚开关状态** + 错误提示
- 状态为“已发布”的记录，前端/用户端才可见（需与后端确认可见性规则）

#### 操作按钮

| 按钮 | 样式 | 交互 |
|------|------|------|
| 编辑 | 蓝色底白字小按钮 | 点击 → 打开编辑弹窗，表单回填该行数据，提交调用更新接口 |
| 删除 | 红色底白字小按钮 | 点击 → **二次确认弹窗**（“确定删除该日志吗？”），确认后调用删除接口，成功后刷新列表 |

**删除补充规则：**
- 删除当前页最后一条数据后，页码应自动回退到上一页（page-1）
- 删除成功提示「删除成功」

#### 空状态
- 列表无数据时显示空状态占位图 + 文案「暂无数据」
- 搜索无结果时显示「未找到匹配的日志」

## 4. 分页组件规格

| 属性 | 规格 |
|------|------|
| 分页器 | 上一页 `<`、页码（当前页高亮蓝色）、下一页 `>` |
| 跳转 | 「前往 [input] 页」+ 单位「页」，输入页码回车或失焦跳转 |
| 总数 | 右侧文案：`共 15 条记录`（动态读取 total 字段） |
| 默认 pageSize | 10 条/页（当前展示 10 行、共 2 页，15 条 ÷ 10 = 2 页 ✓） |
| 边界处理 | 第一页禁用 `<`，最后一页禁用 `>`；跳转输入超出范围需 clamp（最小 1，最大总页数） |
| 切换页码 | 滚动回列表顶部，重新请求数据 |

## 5. 接口设计建议

### 5.1 分页查询
```
GET /api/logs/page
参数: pageNum=1, pageSize=10, keyword=(可选)
响应: {
  "total": 15,
  "list": [{
    "id": 1,
    "title": "冒烟测试",
    "type": "AI自习室通知",
    "createTime": "2025-08-27 22:53",
    "publishStatus": 0,   // 0-未发布 1-已发布
    "viewCount": 0
  }]
}
```

### 5.2 其他接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/logs` | POST | 新增日志 |
| `/api/logs/{id}` | PUT | 编辑日志 |
| `/api/logs/{id}/status` | PUT | 切换发布状态 `{publishStatus: 0\|1}` |
| `/api/logs/{id}` | DELETE | 删除日志 |

---

## 6. 数据与状态管理

- 列表数据、`total`、`pageNum`、`keyword` 存于页面状态
- 搜索、翻页、切换状态、删除后均需同步刷新数据
- **建议**：接口返回前展示表格 loading 态（骨架屏或加载动画）

## 7. 视觉规范（基于原型）

| 项目 | 规格 |
|------|------|
| 表头 | 白色背景、灰黑文字（`#333`）、底部 1px 分隔线 |
| 行分隔 | 1px 浅灰线（`#EBEEF5`） |
| 行高 | 约 56px，行间距均匀 |
| 主色 | 蓝 `#409EFF` / `#1890FF`（按钮、当前页码、开关选中态） |
| 危险色 | 红 `#F56C6C`（删除按钮） |
| 圆角 | 按钮/输入框 4px；外层卡片 8px |
| 字号 | 正文 14px，表头 14px（可加粗或加深色） |

## 8. 异常与边界场景

| 场景 | 处理方式 |
|------|---------|
| 接口请求失败 | 表格展示错误提示，可重试 |
| 标题过长 | 单行省略 + tooltip 完整展示 |
| 点击量为 0 | 正常显示数字 `0`，不隐藏 |
| 并发点击开关 | loading 锁定，防抖处理 |
| 删除已发布日志 | 建议确认弹窗中给出更强警示文案（需产品确认） |
| 权限控制 | 编辑/删除/新增按钮按角色权限控制显隐（需与后端确认） |

## 9. 待产品确认的问题（Open Questions）

1. **发布状态**切换是否影响 C 端可见性？已发布内容是否允许再次下线？
2. **类型字段**是固定枚举还是可配置字典？目前仅一种「AI自习室通知」。
3. **点击量**统计来源（C 端浏览埋点？）是否需要排序查看？
4. 删除是否为**物理删除**，还是软删除（可回收站恢复）？
5. 新增日志时是否支持**定时发布**？
